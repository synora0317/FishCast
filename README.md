# FishCast — 수산물 매입 AI 예보

수산물을 사들이는 가공업체·유통업체가 **언제 사는 게 유리한지** 판단할 수 있도록, 위판 가격을 예측해 매입 시점을 추천하는 모바일 웹앱입니다.

> 📱 모바일 화면에 맞춰 설계되어 있어 휴대폰으로 보는 것을 권장합니다.

## 주요 기능

### 1. 매입 추천
- 어종을 고르면 **"지금 매입 / ○일 후 매입 / 보류"** 중 하나를 추천하고 그 이유를 보여줍니다.
- 7일 가격 예측 차트와 일별 매입 전략(매입적기 / 관망 / 보류)을 함께 제공합니다.
- 추천 규칙
  - 7일 예측가가 모두 현재가보다 높으면 → 지금 매입
  - 7일 내 저점이 현재가보다 3% 이상 낮으면 → 저점일까지 대기
  - 차이가 3% 미만이면 → 기다리는 이득이 작으므로 지금 매입

### 2. 가격 예보
- 최근 30일 실제 위판가 추이와 일별 가격 예보를 보여줍니다.

### 3. 신선도
- 기상청 울산 해양기상부이의 **실시간 수온**을 불러와 신선도 등급과 냉장 보관 시 부패 예상 시간을 표시합니다.
- 최근 7시간 수온 변화 추이 차트를 제공합니다.

### 4. 리스크
- 어종별 7일 내 **가격 폭등·폭락 리스크 점수(0~100)**를 계산합니다.
- **원가 목표 시뮬레이터:** 목표 매입 단가를 입력하면 7일 안에 달성 가능한 날짜를 예측합니다.

## 예측 모델과 검증

- **데이터:** 해양수산부 수산물 위판 공공데이터
- **모델:** XGBoost 기반 일별 가격 예측
- **검증:** Walk-Forward 방식으로 과거 시점부터 순차적으로 학습·예측해, 미래 데이터가 학습에 섞이지 않도록 했습니다.

| 어종 | 가격 방향 예측 정확도 |
|---|---|
| 멸치 | 69.6% |
| 고등어 | 69.1% |
| 삼치 | 67.9% |
| 넙치 | 65.0% |
| 갈치 | 63.5% |

> 방향 정확도: 다음 날 가격이 오를지 내릴지를 맞힌 비율

## 한계와 개선 방향

- 현재 버전은 **프로토타입**입니다. 가격 예측은 2026년 5월 31일까지의 데이터로 미리 계산해 페이지에 넣었고, 자동 갱신 파이프라인은 아직 없습니다.
- 부패 예상 시간은 수온에 비례하는 단순 공식으로 계산한 참고값입니다.
- 위판량·입항 척수는 데이터가 없어 표시되지 않는 어종이 있습니다.
- 알림·데이터·설정 메뉴는 화면만 있고 기능은 구현되지 않았습니다.
- 다음 단계: 예측 자동 갱신, 서버를 통한 API 호출, 예측 구간(불확실성) 표시
